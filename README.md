# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping platform designed for houseplant enthusiasts. The web application allows users to explore a diverse collection of indoor plants categorized into multiple types (Air Purifying, Aromatic, Low Maintenance), view plant details, add items to a dynamic cart, and seamlessly manage item quantities and totals.

## Features:
* Landing page with introduction and "Get Started" navigation.
* Multi-category plant listing with thumbnails, descriptions, and pricing.
* Interactive shopping cart powered by Redux Toolkit.
* Dynamic quantity updates and real-time total calculation.
* Responsive and visually appealing design.
